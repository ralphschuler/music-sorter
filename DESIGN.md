# Music Sorter design

Music Sorter is a local library tool, not a streaming service or a cloud dashboard. The reference is a record index: clear alphabetical structure, small track metadata and an uncomplicated route from a folder to a sorted library.

## Visual direction

- Light neutral paper, dark ink and a single ultramarine accent (`#2549D8`). Use the accent for the task's main action, keyboard focus and links, not for decoration.
- Typography and spacing carry the hierarchy. Use thin rules, modest corner radii and quiet text states, not gradients, pill collections, layered cards or stock artwork.
- On the website, the actual desktop index is the lead asset. A second genuine app capture shows folder setup. The accompanying text says what the controls do, rather than restating their labels.
- In the app, keep the order: profiles, folder and pattern setup, index, optional review, sorting progress. Show one primary action on the active screen. Preserve existing behavior, offline defaults and safety rules.
- Use synthetic tracks in screenshots. No real filesystem paths, personal music, secrets or user profiles in assets or public copy.

Design references: [Impeccable](https://github.com/pbakaus/impeccable) (visual hierarchy, critique and accessibility) and the [Avalonia Fluent theme](https://docs.avaloniaui.net/controls/themes/fluent/).
