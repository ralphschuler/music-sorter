# Profile wizard
Ralph chose a multi-screen desktop flow over the single-screen prototype. Open on saved profiles, or create one with two short steps: select multiple source folders and one output folder, then choose the path pattern and name the profile. Never modify audio when selecting, saving or opening a profile. Opening a profile displays its local index immediately if cached. While open, refresh it after filesystem changes, including local hashes, tags and available fingerprints, without reminders or external lookups. Present the index and one primary Start sorting button. Keep optional manual metadata review behind a separate screen; unknown matches never block sorting and are retained as separate files. Export continues to copy only, and never overwrites or deletes originals. Windows and Mac support from one Avalonia app. No persistent background daemon.
