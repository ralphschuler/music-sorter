# Music Sorter

The current navigation replaces the single-screen prototype; see [Profile wizard](2026-11-21-profile-wizard-design.md).

A native Avalonia desktop tool on .NET 11, Windows-first with the same app tested on macOS. A local browser app would require a separate local server for filesystem access; desktop is selected. A selected source is enumerated recursively, with bounded parallel local metadata and hash reads and incremental progress. Index locally. Users compose a relative scheme using tokens and literals, review the destinations, then apply. A separate opt-in metadata adapter may look up artist/title (never the full path or audio), offering candidates without replacing populated fields. The third optional lookup fallback is Chromaprint, computed locally and persisted by original SHA-256. Equal audio fingerprints across different hashes flag possible duplicates, not exact duplicates. AcoustID lookup is explicit, sends fingerprint and duration only (plus the application key) and never sends audio or automatically writes suggestions.
Default export copies; preview never modifies music. Skip byte duplicates based only on SHA-256 of the original file. Keep different hashes with the same normalized nonempty artist and title as visibly flagged variants; never infer identity from tags. Paths are safe for Windows, collision-safe and non-overwriting. Export stages and validates copies before publishing; no source deletion in the initial implementation. All verification uses synthetic test files, not Ralph's library.
